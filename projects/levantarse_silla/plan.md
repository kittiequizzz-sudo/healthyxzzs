# Scene plan: "El ejercicio de la silla" (levantarse de la silla, 60+)

~2,900 spoken words → ~19–20 min. Built and delivered in 3 parts (owner's request): **parte 1** = intro + punto1 + punto2 (assets: `order_parte1.md`), **parte 2** = punto3 + punto4, **parte 3** = punto5 + punto6 + conclusion. Sections = the script's parts: `intro`, `punto1` … `punto6`, `conclusion`.
Same build as `projects/7dias_sin_cenar` (one HTML per section, `common.js`, parallel render).

Character: **Antonio** (new, 67, same blue-skin art style, ordinary build, NOT the bodybuilder senior_m:
the story is about legs losing strength). He is both the story and the exercise model.

Recurring visuals:
- **Progress strip** (top right): 6 small icons: pasos · cronómetro · músculo · silla · reloj 5' · cerebro.
- **"Coche" metaphor**: steady motor = walking, accelerating up a hill = getting up.
- **Chair** cut-out used as a stage for diagrams.
Picture sources: S = scene panel, P = pose (cut), I = item cut-out, C = code diagram.

Drawing budget: ~19 min → 57–76 picture beats at 1 per 15–20 s. Ordered: 16 scene panels (A–D) + 8 poses
(E, F) + 4 fault panels (G) + 11 items (H, I) = 39 new drawings, reused cut-outs (brain, heart, liver, calf,
body, dumbbells from `7dias_sin_cenar` / `azucar_sube`), and code diagrams (stopwatch, counters, car RPM,
tempo bar, routine builder, calendar, fear loop) for the rest. Every drawing returns 1–3 times.

Panel names: A `a_sofa a_paseo a_escalera a_nietos` · B `a_tropiezo a_cama a_mesa a_telefono` ·
C `a_desayuno a_nietos_ok a_victoria a_suelo` · D `m_coche_llano m_coche_subida a_prueba a_miedo` ·
E poses `sts_1..4` · F poses `n1_1 n1_2 n1_3 n3_hover` · G faults `f_rodillas f_talones f_caer f_bien` ·
H `silla silla_brazos cojin escalon alfombra zapatillas` · I `muslo cadera_hueso pierna_venas fibra rodilla`.
