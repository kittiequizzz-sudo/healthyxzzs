Map data and projection code for `scripts/map_paths.mjs` (offline; the CDN is blocked in the cloud box).

- `countries-50m.json`, `countries-110m.json`: world-atlas 2.0.2 (ISC licence, Mike Bostock), built from
  Natural Earth (public domain).
- `d3-geo.min.js` 3.1.0, `d3-array.min.js` 3.2.4, `topojson-client.min.js` 3.1.0: ISC licence (Mike Bostock).

Country names are Natural Earth's English names ("Mexico", "Brazil", "United States of America").
Borders shown on screen are Natural Earth's de-facto boundaries; label them "Mapa ilustrativo" if a border
matters to the story.
