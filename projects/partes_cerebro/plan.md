# Scene plan: "Las partes del cerebro"

~3,030 spoken words → ~20–21 min at 150 wpm. Built like `projects/7dias_sin_cenar/` (one HTML per section on the
shared voice timeline, `common.js`, `render_sections.mjs --jobs 3`). Sections: `intro`, `punto1` … `punto5`,
`conclusion`. Rules: `youtube-style.md`.

Characters: **Don Manuel** (`characters/manuel/sheet.webp`, approved) and his wife **Doña Elena** (new, defined in
the order and drawn in the same 2D film style). Both appear only in 2×2 scene panels shown as push-in stills.

## Core visual device: the brain map
- `G1` lateral brain in flat, clearly separated colours: frontal orange, parietal yellow, temporal green, occipital
  purple, cerebellum pink, brainstem teal; plus the same brain uncoloured. The cutter extracts each region by its
  colour, so in code each lobe can **light up** on its word while the others dim to the uncoloured brain.
- `G2` mid-sagittal slice in flat colours: corpus callosum light blue, thalamus orange, hypothalamus yellow,
  pituitary red, midbrain teal, pons blue-green, medulla dark teal, cerebellum pink; plus the uncoloured slice.
- `G3` items: limbic view (hippocampus green + amygdala purple inside a faint brain), coronal slice (caudate +
  putamen purple, substantia nigra dark), a neuron, a spinal cord + brainstem, eye, ear, nose icon-like drawings.
- **Progress strip** top right: 5 small region icons (lobes · memoria · centro · movimiento · tronco), current ringed
  orange. **Stroke card** (red, code-drawn) reused 4×.

Drawings: 3 item sheets (~20 cut-outs) + 6 scene sheets (24 panels) ≈ 44 drawings, ≈ 1 per 28 s; the brain map
highlights change every 3–5 s, so the "picture every beat" rule holds. If a section looks thin at QA, order a 7th sheet.

- Occipital (purple): eye → occipital arrow; visual field circle with a missing quarter "ver ≠ ojos sanos".

- Bridge: G1 fades to G3 limbic view "bajo la **SUPERFICIE**".

## punto2 — hipocampo y amígdala (~3:20)

- Amnesia: two timelines: old memories ✓ (decades) vs today ✗ (breakfast). Term "AMNESIA ANTERÓGRADA".

- Amygdala alert: `s_startle` (bang) + lightning icon "**ALERTA**". "¿centro del miedo? NO" stamp → network.

- "memoria + emoción" interlinked rings. "Empatía".
- Consult card (amber): "progresivo · afecta tu autonomía → **CONSULTA**".
- Subscribe CTA; teaser: hypothalamus outline + hunger · thirst · sleep icons.

## punto3 — tálamo, hipotálamo, hipófisis (~3:20)
- Kicker "3 · LOS CONTROLES OCULTOS" over G2.

- Bridge: glass of water icon, shirt button, walking → cerebellum outline.

## punto4 — cerebelo y ganglios basales (~3:20)

  habla.

- Comparison card: cerebelo = **corrige** · ganglios = **decide qué y cómo**.
- "¿lento o de golpe?" two curves (slow slope vs sudden drop).
- Stroke card #2 (equilibrio · habla · visión doble · un lado · dolor súbito), `s_emergency` → "NO ESPERES".
- Green "temblor ≠ siempre Parkinson".
- Bridge: sleeping breath → brainstem.
