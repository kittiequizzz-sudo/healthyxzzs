# mascot_pastel: warm pastel 2D round-head mascot (owner's style, Oct 2026)

`sheet.jpg` is the owner's character sheet (round white face, curly dark-brown hair, round glasses, rosy cheeks,
mustard-yellow T-shirt, beige trousers, dark-brown shoes). `cut/` holds the seven poses cut with `cut_items.py`.
Gemini sheets carry a small sparkle watermark at the bottom right: crop or mask it before use.

Code theme for videos in this style (see `style_test.html` → `style_test_0.png`, approved look pending):
cream `#FCEDCE`, ink `#4A3428` (warm brown, not black), white `#FFFDF7`, amber `#FBB533`, orange `#F4A340`,
red `#E8735F`, green `#79B98A`, blue `#8EC5E8`, grey `#BBA994`, card shadow `#EBD3A8` (soft, no hard black offset),
outlines 3–5 px, radius 36+, pastel blobs behind cut-outs. Use code-drawn icons, not emoji, in real videos.
